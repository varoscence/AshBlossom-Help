# 💬 Chat Games

Quick games right in the chat. Be the first to type the right answer!

***

### 🎮 How it works

Every few minutes a new game pops up in chat. Type your answer as a normal chat message. The first player with the correct answer wins the round.

| Game | What you do |
| --- | --- |
| Trivia | Answer the question. |
| Math | Solve the sum. |
| Unscramble | Unscramble the letters to find the word. |
| Multiple Choice | Pick the right answer: A, B, C or D. You only get one guess per question. |
| Reaction | Type the word shown as fast as you can. |

### 🔀 Shuffle rounds

Sometimes staff start a **Shuffle Round**: one question from every game type, back to back.

> [!TIP]
> Answers are short: usually one word, name or number. Speed matters, so keep your chat open!
