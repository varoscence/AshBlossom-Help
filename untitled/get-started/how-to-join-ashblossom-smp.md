# 🌿 How to Join: AshBlossom SMP

Connecting to our "Forever World" is easy! We are a Cross-Play server, meaning Java and Bedrock players can build together.

#### 🖥️ Java Edition (PC)

For the best experience, we recommend using the latest stable release.

1. Version: Launch Minecraft 1.21.1 (or the latest sub-version).
2. Navigate: Select Multiplayer > Add Server.
3. Server Address: `ashblossom.com`
4. Connect: Hit "Done" and double-click to join!

#### 📱 Bedrock Edition (Mobile, Console, Win10)

Play on the go or from your couch!

1. Navigate: Click Play > Servers tab.
2. Add Server: Scroll to the bottom and click Add Server.
3. Server Name: AshBlossom
4. Server Address: `ashblossom.com`
5. Port: `27999`

***

#### ⚠️ Important Notes

* Username Prefix: Bedrock players will have a (\*) before their name (e.g., `*PlayerName`). This is a special tag that allows our Java/Bedrock bridge to work seamlessly!
* Need Help? If you can't connect, please ensure your game is fully updated or open a ⁠[Ticket](https://www.google.com/search?q=https://www.ashblossom.com/support) on our Discord.
