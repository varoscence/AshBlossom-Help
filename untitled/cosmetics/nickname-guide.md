# 🎭 Nickname Guide

***

#### Nick requires Rank: [Store](https://ashblossom.tebex.io/category/Ranks)<br>

***

\
Use `/nick` to change how your name appears in chat.

**Set a nickname**

```
/nick <name>
```

Example:

```
/nick player
```

**Use colors**

```
/nick &cShadow
```

**Example color codes**\
`&c` red • `&6` gold • `&e` yellow • `&a` green • `&b` aqua • `&9` blue • `&d` pink • `&f` white\
\
<sup>**Emberling: white, red, gold, yellow**</sup>\ <sup>**Flamebound: green, dark green**</sup>\ <sup>**Starseeker: aqua, blue, dark blue**</sup>\ <sup>**Ashwarden: light purple, dark purple**</sup>\ <sup>**Phoenixborn: all colors + rgb**</sup>
