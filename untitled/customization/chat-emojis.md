# ☻ Chat Emojis

AshBlossom supports emoji shortcuts in **chat, signs, books, and anvils**. Simply type any of the shortcuts below and they will automatically be replaced!

***

### Faces & Emotions

| Shortcut                                                  | Symbol |
| --------------------------------------------------------- | ------ |
| `:)` `':-)` `=)` `:smile:` `:happy:` `:D` `:-D`           | ☺      |
| `;)` `;-)` `:wink:`                                       | ☻      |
| `:sob:` `:cry:` `:crying:`                                | ☹      |
| `<3` `:heart:` `:love:` `:ily:` `:heartbeat:` `:loveyou:` | ♥      |
| `</3` `:brokenheart:` `:broken:`                          | †      |
